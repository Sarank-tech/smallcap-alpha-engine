# NSE Multibagger System — Execution & Operational Guide

This document provides a reference guide for running, cleaning, customizing, and viewing the outputs of the **5-Stage NSE Smallcap Multibagger Discovery System**.

> **Project Root:** `/Users/admin/Developer/smallcap-alpha-engine/`
> **Pipeline Scripts:** `pipeline/` folder
> **All Outputs:** `outputs/` folder

---

## 🚀 Quick Execution Commands

All commands should be run from the project root directory:

```bash
cd /Users/admin/Developer/smallcap-alpha-engine
```

### 1. Run Complete 5-Stage Pipeline (Single Command)
Executes Stage 1 through Stage 5 in sequence, generates all output CSVs, markdown reports, and builds the interactive `index.html` dashboard:

```bash
python3 run_pipeline.py
```

---

### 2. Clean & Run Fresh Pipeline (Single Command)
Wipes all previous output CSV files, log files, and `index.html`, then executes the full pipeline from scratch:

```bash
python3 run_pipeline.py --clean
```

---

### 3. Standalone Cleanup Commands
If you want to remove generated output files without running the pipeline immediately:

```bash
# Clean CSVs, Markdown/PDF reports, logs, and index.html:
python3 clean_pipeline.py

# Clean CSVs, reports, logs, index.html, AND the research/ folder:
python3 clean_pipeline.py --all
```

---

## 💰 Customizing Portfolio Capital Investment

Portfolio position sizing and rupee allocation calculations apply at **Stage 5 (`pipeline/stage5_portfolio.py`)** and automatically reflect in `outputs/portfolio_plan.csv`, `outputs/portfolio_strategy_report.md`, and `index.html`.

### Method 1: Edit line 40 in `run_pipeline.py` (Default = ₹1 Lakh)
Open `run_pipeline.py` and change `PORTFOLIO_CAPITAL_INR`:
```python
# Default portfolio capital investment passed to Stage 5:
PORTFOLIO_CAPITAL_INR = 100000.0  # Modify here (e.g. 2500000.0 for ₹25L)
```

### Method 2: Pass `--capital` CLI argument
```bash
# Example: ₹25 Lakhs Portfolio Capital
python3 run_pipeline.py --capital 2500000

# Example: ₹50 Lakhs Portfolio Capital
python3 run_pipeline.py --capital 5000000

# Example: Clean & Run with ₹10 Lakhs Portfolio
python3 run_pipeline.py --clean --capital 1000000
```

## 🎯 Selective Stage Execution Options

If you want to re-run only a specific stage:

```bash
# Run ONLY Stage 5:
python3 run_pipeline.py --stage 5

# Resume pipeline starting from Stage 3 onwards:
python3 run_pipeline.py --from-stage 3
```

## 🌐 Opening the Interactive HTML Dashboard on macOS

To view the interactive dashboard in your Mac's default browser (Safari, Chrome, Arc, etc.):

```bash
open index.html
```

Or manually double-click `index.html` in Finder.
